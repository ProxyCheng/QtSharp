# Security Policy

## Supported versions

Only the current `master` branch is actively maintained until a release policy is established.
The project is pre-1.0 and does not yet promise long-term binary compatibility.

## Reporting a vulnerability

Please do not open a public issue for an exploitable vulnerability. Use GitHub's private security
advisory flow for this repository, or contact the maintainers through the email address listed in
the repository owner's GitHub profile. Include a description, affected commit or package version,
reproduction steps, impact, and a suggested mitigation if available.

You should receive an acknowledgement within seven days. We will coordinate a fix, credit the
reporter when requested, and publish a security advisory after users have had a reasonable chance
to upgrade.

Do not send Qt SDK files, credentials, personal data, or other sensitive material in a report.
